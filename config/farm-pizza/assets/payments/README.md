# Card marks

Drop the official SVGs in here and the footer shows them. Nothing here means
the footer says "Card payments taken securely online" in words instead, which
is honest and still reassuring — it is not broken, it is the fallback.

These must be the real files from each scheme's own brand centre. A drawn
approximation is worse than no badge: it reads as fake immediately, which is
the opposite of what the badge is for, and the schemes require their marks to
be reproduced exactly. All of these are free.

| File | Where to get it |
|---|---|
| `visa.svg` | https://usa.visa.com/run-your-business/small-business-tools/payment-technology/visa-brand-assets.html |
| `mastercard.svg` | https://brand.mastercard.com/brandcenter/mastercard-brand-mark.html |
| `amex.svg` | https://www.americanexpress.com/us/merchant/logo-and-signage.html |
| `apple-pay.svg` | https://developer.apple.com/apple-pay/marketing/ |
| `google-pay.svg` | https://developers.google.com/pay/api/web/guides/brand-guidelines |

Use the horizontal, full-colour version of each, on a clear background — the
footer already puts a white plate behind them. Name the file exactly as above;
anything else is ignored. `.png` works too if a scheme only offers that.

Only add a mark for something the shop genuinely accepts. Apple Pay and Google
Pay only apply once Stripe is live and those wallets are switched on.
